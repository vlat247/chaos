> Built in memory of Zhansar — the friend who showed me what programming could be.  
> He died in a car accident. This app carries his name.

**Chaos** is a note-taking app where your thoughts live by tag, not by folder.  
Write a note, tag it, find it instantly. Like Obsidian — but lighter, faster, and in your browser.

**Live →** [chaos-zhansar.vercel.app](https://chaos-zhansar.vercel.app)

---

## Features

- **Tag-based organization** — no folders, no hierarchy, just tags that connect your thoughts
- **Chat-like interface** — write notes the way you think, not the way a spreadsheet wants you to
- **Instant search** — find any note by tag in milliseconds
- **Clean, minimal UI** — nothing in the way between you and your thoughts

npm run dev
